# SunamoUiPreferences

## Short description

Malá knihovna pro volbu jazyka a barevného motivu ve Windows desktopových appkách (podle systému, nebo pevně zvolená hodnota) včetně uložení obou voleb do `ui-settings.json`.

Nezávisí na žádné UI knihovně. Appka si výsledek (jazyk, světlý nebo tmavý motiv) sama promítne do své UI knihovny přes události.
